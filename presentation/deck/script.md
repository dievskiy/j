# Narration and shot list

Total: 120 s, 300 words (about 2.5 words per second). Generated by `scripts/build_deck.py` from `scripts/deck_data.py`. Edit there.

Open `index.html` (arrow keys, `n` for notes, `t` for timed autoplay) or upload `deck.pdf`.

## Narration

### 1. LLMs in physical challenges (0:00–0:08, 8 s, 19 words)

> Frontier agents ace benchmarks. Put one in charge of an unfamiliar machine, and it must test before it acts.

### 2. 75 maps over 2 environments (0:08–0:22, 14 s, 38 words)

> Two MuJoCo worlds. A rover must find the one passable lane. A crane must find the one liftable crate. The map never says which. A cheap test does, and the budget allows that test, not a wrong guess.

### 3. The agent touches the simulator only through tools (0:22–0:32, 10 s, 25 words)

> Agents reach the simulator only through MCP tools, under Harbor and OpenCode. Reward comes from simulator state alone. Doing nothing, or stopping early, scores zero.

### 4. Every run lands far below the reference (0:32–0:44, 12 s, 31 words)

> On seventy-five frozen tasks, our scripted reference, using the same tools, delivers every time. DeepSeek delivers forty-five percent. Inkling, twelve. Three runs each, and every run is far below the reference.

### 5. Tests, then ignores the evidence (0:44–1:03, 19 s, 45 words)

> Why? Same task, two agents. Inkling crawls across the mud sample for fifty seconds, decides it is not on mud, then drives into the mud lane and stalls. DeepSeek gets stuck on the same sample, calls the mud impassable, and takes the ice lane home.

### 6. The test that breaks the thing it measures (1:03–1:20, 17 s, 42 words)

> On the crane, a careless test breaks what it measures. Inkling weighs a crate with one long pull. The tension stop is a trigger, not a cap, and the cable snaps in under two seconds. DeepSeek weighs in short pulls and delivers.

### 7. Looking for a shortcut instead of solving the task (1:20–1:33, 13 s, 38 words)

> After failing, Inkling hunts for a shortcut. It reads the result file, then opens a fresh session with curl. It finds the same ended episode and a read-only result. Nearly a thousand such calls, and none earned reward.

### 8. Not one-offs: the failures are decisions (1:33–1:44, 11 s, 27 words)

> These are not one-offs. After testing, DeepSeek enters the open lane ninety-four percent of the time. Inkling, sixty. Chance is forty-six. The map held everything they needed.

### 9. Fine-tuning a smaller model did not help (1:44–1:53, 9 s, 17 words)

> We also fine-tuned a small Qwen model on its own successful episodes. Honestly, it did not improve.

### 10. Test before you commit (1:53–2:00, 7 s, 18 words)

> One command reproduces all of it. Test before you commit: a gap that comes from decisions, not tricks.

## Replay check

Every simulation frame comes from replaying the trial's recorded MCP tool calls
(`agent/trajectory.json`) on a fresh episode, on a copy of the trial directory under
`presentation/deck/work/`. `scripts/replay_frames.py` compares the replayed reward, end time
and reason with `verifier/sim_result.json`.

## Regenerate

```bash
presentation/deck/scripts/render_all.sh                    # copy trials, replay, render frames (needs MUJOCO_GL=egl)
python3 presentation/deck/scripts/make_charts.py           # SVG charts and the harness diagram
.venv/bin/python presentation/deck/scripts/build_deck.py   # slide images, deck.pdf, index.html, script.md
```

`deck.pdf` is the file to upload (PDF, under 20 MB). If a second fine-tuning round should be
shown, set `ROUND_2_MEAN` in `scripts/deck_data.py` and rerun the last two commands.
